# Dronepad HQ — Operational Workspace

Questa versione è pensata come strumento operativo quotidiano per seguire il progetto Dronepad.

## Funzioni principali

- **Dashboard di avanzamento**
  - indice operativo calcolato automaticamente;
  - attività degli ultimi 7 giorni;
  - prospect avanzati nella pipeline;
  - task completati;
  - follow-up e scadenze dei prossimi 14 giorni.

- **Registro di progetto**
  - ricerca;
  - investitore;
  - contatto;
  - meeting;
  - strategia;
  - competitor;
  - bando / finanziamento;
  - prototipo;
  - documento;
  - altro.

  Ogni voce può contenere data, organizzazione, risultato, note, link/fonte, prossima azione e scadenza.

- **Pipeline investitori**
  - aggiunta prospect;
  - modifica completa;
  - eliminazione;
  - stadio;
  - priorità;
  - referente;
  - contatto;
  - sito;
  - ultimo contatto;
  - follow-up;
  - note.

- **Prototype readiness**
  - checklist operativa;
  - avanzamento percentuale.

- **Piano di lavoro**
  - task;
  - scadenza;
  - responsabile;
  - stato;
  - modifica ed eliminazione.

- **Archivio**
  - Data Room privata locale;
  - fonti e link salvati automaticamente dal Registro e dalle schede investitore.

## Salvataggio

La piattaforma funziona subito anche senza servizi esterni:
- dati salvati nel browser;
- documenti salvati localmente tramite IndexedDB;
- export di backup JSON.

La cartella `supabase/` contiene anche lo schema aggiornato per attivare, quando desiderato:
- login;
- database condiviso;
- sincronizzazione multi-dispositivo;
- storage privato cloud.

## Mobile

La piattaforma è responsive e include:
- navigazione mobile;
- CRM a card;
- registro attività a colonna;
- form adattivi;
- Data Room e task board ottimizzati per smartphone.


## Blue Neon
Aggiunti effetti visuali blu molto leggeri:
- meteore/scie luminose occasionali;
- aloni blu in movimento sullo sfondo;
- sweep sottili sulle intestazioni;
- piccoli scan luminosi su CTA e navigazione attiva;
- versione alleggerita su smartphone.
