# Dronepad Investor Hub — Visual Final

Versione focalizzata sulla pipeline investitori, ma con una vera **home hub** introduttiva e più immersiva.

## Struttura
- `index.html` — home hub / dashboard introduttiva;
- `pipeline.html` — CRM e pipeline investitori;
- `investor.html` — scheda dettagliata del singolo investitore;
- `data.js` — dati, seed, traduzioni IT/EN;
- `app.js` — logica applicativa;
- `styles.css` — grafica, responsive, animazioni, effetti neon;
- `assets/` — logo e immagini concept.

## Cosa è stato aggiunto
- scritta hero **DRONEPAD** con impatto visivo;
- introduzione più chiara;
- immagini concept nella home;
- card introduttive;
- marquee testuale in movimento;
- scritte con glow / sweep luminoso;
- comparsa degli elementi in scroll;
- flare neon sullo sfondo;
- scie luminose blu che scendono dall'alto verso il basso con lieve inclinazione;
- pipeline ancora al centro del progetto.

## Funzioni operative
- dashboard sintetica;
- filtri e ricerca nella pipeline;
- apertura scheda investitore;
- modifica / eliminazione prospect;
- cronologia attività;
- aggiunta attività;
- backup JSON;
- interfaccia IT / EN;
- layout mobile.

## Nota
Gli effetti visivi sono pensati per dare presenza e storytelling senza togliere chiarezza alla piattaforma.
